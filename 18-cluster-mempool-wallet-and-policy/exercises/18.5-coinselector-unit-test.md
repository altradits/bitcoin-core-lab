# Stage 18 Exercise 18.5: Write a coin-selection unit test in C++

**Output:** a new `BOOST_AUTO_TEST_CASE` in your **master worktree** (Stage 17's
`/Users/mac/bitcoin-fuzz` or another), on a topic branch, built and passing.
**Checker:** `./check_18.sh unit` (finds your case in the worktree and runs it with `test_bitcoin`)

## Goal
Add a test case named `kisumu_bnb_exact_match` to `src/wallet/test/coinselector_tests.cpp` that:
1. Builds a UTXO pool of at least four coins with known values (read how existing BnB tests build
   pools — look for the helper that adds a coin to a pool in that file).
2. Asks `SelectCoinsBnB` for a target that one **combination** of two coins matches exactly
   (within `cost_of_change`), and asserts that the selection contains exactly those two coins.
3. Asks for a target that **no** combination matches within `cost_of_change`, and asserts that BnB
   returns an error (no result) — the wallet would then fall back to other algorithms.

## Steps
1. Read `bnb_search_test` in the same file first. Write down the helper names and the fixture.
2. Write your test. Build **only** `test_bitcoin` (Stage 13: single target, limited `-j` on 8 GB).
3. Run only your case: `test_bitcoin --run_test=coinselector_tests/kisumu_bnb_exact_match`.
4. Mutation: change one asserted coin value; the test must fail. Restore it.
5. Commit on your topic branch with a message in Core style (`test: ...`) — **do not** push or
   open a PR from this exercise; it is practice (Stage 19 covers real contributions).
