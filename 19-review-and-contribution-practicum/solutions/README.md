# Stage 19 solutions (spoilers)

- `self-check-answers.md`: answers to the README self-check quiz. Open it only after you
  have written your own answers, or after 3 honest attempts.
- **There are no Gauntlet model reviews here, on purpose.** The answer key for each round is
  the real GitHub review thread, written by real reviewers. Your comparison file is where you grade
  yourself against it.

  links, and a branch that passes `check_commit_hygiene.sh`.
